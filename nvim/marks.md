# Marks

vim remembers the position before a jump.  
jmp: including search , `j` `k` not included.

- use `` to jump back
- `Ctrl-O` older positions
- `Ctrl-I` newer positions

## named marks

- `ma` mark cursor as `a`  
- `a goes back.  
- `'a` == `a 0

special marks:
- `'` cursor position before doing a jump
- `"` cursor position of last edit
- `[` start of last change
- `]` end of last change
